# Legacy vendored sources

This directory contains historical third-party source files from the former custom Loka Arduino library.

They are **not used**, **not supported**, and are intentionally excluded from the hardware-first project structure. New users should install the official CodeCell and SparkFun VL53L5CX libraries through Arduino Library Manager and use the standalone sketches in [`../examples`](../examples).

The former Loka wrapper entry points and `library.properties` file have been removed, so this repository is no longer distributed or documented as an Arduino library.
